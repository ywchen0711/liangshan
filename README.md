# 梁山群英傳 · Heroes of the Marsh

吞食天地、諸葛孔明傳風格的 RPG，故事是《水滸傳》。

- **走遍北宋的山河**（像素畫的大地圖：草原、農田、沙灘與雪原在邊上互相交錯，岸邊有浪花，樹林、丘陵、雪峰描著黑線立在地面上；戰場上的將領、兵卒和背景也是同一種畫風：騎將坐在配了鞍韉、轡頭的戰馬上，身披甲片、背後飄著戰袍，手上拿著自己的兵器；身後的兵卒依兵種是持盾長槍兵、弓兵、騎兵、水軍或擎旗的謀士兵，兩軍陣後各有一面寫著「梁」「宋」「遼」等字的大旗迎風飄動）：從陝西的史家村、渭州，到東京汴梁、梁山泊、大名府、江州，北上遼國燕京，南下方臘的江南八州。黃河、長江、太行山、梁山泊的蘆葦蕩，九十個城鎮、山寨、寺廟和名勝。
- **跟著原著走**：王進傳棒、魯提轄拳打鎮關西、林沖風雪山神廟、智取生辰綱、武松打虎、江州劫法場、三打祝家莊、破連環馬、大名府、曾頭市、石碣天書排座次、招安、征遼、征方臘，直到蓼兒洼。
- **吞食天地式的戰鬥**：將領的兵力就是生命。每回合給每位將領下令：攻擊、計策（火計、水淹七軍、五雷正法、飛沙走石、救護、鼓舞、混亂……共 29 種）、道具、防禦、全軍突擊（本回合全員攻擊）、總攻擊（自動戰鬥：每回合全軍集中攻擊最弱的敵將，按任意鍵停止）、撤退；依速度順序行動。騎兵剋步兵、步兵剋弓兵、弓兵剋騎兵；水軍在水上更強。
- **路上遇到的武將都有機會加入**：野外遇到的將領被擊敗後會被擒，可以招降（送禮能提高機會），不肯降的可以押在軍中，隨時從選單的「俘虜」再勸，每在客棧住一晚機會就高一點；各地酒館裡有想上梁山的好漢，還有想先跟你比試的名將（岳飛、韓世忠、周侗、王進……）。
- **500 個人物**：梁山一百單八將，原著裡的官員、惡霸、祝家莊、曾頭市、遼國、田虎、王慶、方臘的將領，北宋、遼、金、西夏的真實人物，以及各地虛構的綠林與官軍將校。每個人都有自己的頭像：老派戰略遊戲的像素頭像，跟《西遊記・八十一難》同一套畫法——在 32×40 的格子上一格一格畫出來，黑線描邊、平塗上色、左上打光；依臉色、頭巾、頭盔、皮帽、道冠、紗帽、鬍鬚和髮色組合，楊志有青記，武松戴鐵箍，綠林山賊個個濃眉怒目、帶著刀疤或眼罩。
- **1000 件裝備**：十八般兵器（刀槍矛戟劍斧鞭錘棍禪杖戒刀弓叉暗器羽扇拂塵火砲流星錘）各二十階、鎧甲頭盔、坐騎、飾品，還有丈八蛇矛、水磨禪杖、青龍偃月刀、雁翎甲、照夜玉獅子這些名器（主人用起來更強，而且會跟著主人成長）。
- **500 種道具**：金創藥、慶功宴、還魂丹、錦囊、計策符、《孫子兵法》等兵書（學會新計策）、虎骨酒等永久提升能力的補品、招降用的禮物、各地名產、劇情道具。
- **梁山根據地**：火併王倫之後，梁山成為你的根據地：休息免費、商店齊全，在忠義堂調度隨行與留守的頭領、勸降俘虜、查看一百單八將名冊。

操作：方向鍵 / WASD 移動，Enter / Z 決定，Esc / X 取消與選單。手機上有虛擬方向鍵和按鈕。

Play: https://ywchen0711.github.io/liangshan/

Pure HTML / Canvas / ES modules, no build step. All art and sound are generated in code. `node tools/test.mjs` checks the data; `node tools/sim.mjs` plays the whole story headless to check the difficulty.
